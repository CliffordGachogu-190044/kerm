Do you need a cookie consent banner?

Based on how this site is built today: no. It doesn't set any cookies, run analytics, or load third-party trackers, so there's nothing here that a consent banner would be covering.

What this site does not use

  • No analytics (no Google Analytics, Meta Pixel, or similar).
  • No advertising or retargeting trackers.
  • No embedded third-party widgets that set cookies.
  • No third-party font loading. Fonts are hosted on this site itself, so your browser never requests them from Google or anyone else.

Outbound links

This site links out to WhatsApp, Instagram, and Google Maps. These are plain links, not embeds, so they don't run anything on this page. Once you click through, you've left this site, and the cookies and tracking on WhatsApp, Instagram, or Google Maps are governed by their own policies, not this one.

If this changes

If Kerm Designer later adds analytics, advertising pixels, an embedded map, a live chat widget, or online payment, that would very likely introduce cookies or similar technology. At that point, this page needs to be rewritten to describe them, and a cookie consent banner would probably become necessary before those features go live.
